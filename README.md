# ✦ Wednesday To-Do List

A simple and practical task management web application built with HTML, CSS, and JavaScript.

## ✨ About the Project

Wednesday To-Do List is a lightweight web application designed to help users organize daily tasks and keep track of their progress.

This project was created as part of my journey to improve my JavaScript skills, understand DOM manipulation, and practice browser-based data storage.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks using Local Storage
- 🔄 Keep tasks available after refreshing the page
- 📱 Simple and user-friendly interface

## 🛠️ Built With

- **HTML5** — Structure and content
- **CSS3** — Styling and layout
- **JavaScript** — Task management and DOM manipulation
- **Local Storage** — Store tasks in the browser

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/orvexaaa/to-do-list-wednesday
```

### 2. Open the Project

Navigate to the project folder and open `index.html` in your browser.

No additional dependencies or installation are required.
